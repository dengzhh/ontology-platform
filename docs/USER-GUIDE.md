# OntoOS 用户手册

面向平台使用者（业务人员/数据分析/管理者），说明「怎么用」而不涉及实现细节。

---

## 一、快速上手（10 分钟）

### 1. 登录

浏览器打开平台地址（如 `http://ontoos.公司内网`），用管理员分配的账号登录。首次登录后立即在「个人设置」修改密码。

### 2. 认识核心概念

| 概念 | 通俗解释 |
|---|---|
| **本体（Ontology）** | 企业的「业务字典」：有哪些对象（设备、工单、客户）、它们有什么属性、彼此怎么关联 |
| **对象类型** | 一类事物的模板，如「设备」「工单」「客户」 |
| **对象** | 具体的一条数据，如「注塑机 F1-IM-2101」 |
| **关联** | 两个对象之间的关系，如「工单属于设备」 |
| **动作** | 对对象可执行的操作，如「报修」「审批」，可配置为需审批 |
| **空间** | 数据隔离边界：组织空间共享业务数据，个人空间放自己的消费/笔记等 |

### 3. 第一次操作：查看并新建一条对象

1. 左侧导航 → **对象浏览器**
2. 顶部选择对象类型（如「设备」）
3. 点右上角 **新建**，填写属性（带 * 为必填）→ 保存
4. 在列表中点该行可打开详情，查看属性与关联对象

## 二、日常工作流

### 录入数据

| 方式 | 路径 | 适用 |
|---|---|---|
| 手动新建 | 对象浏览器 → 新建 | 单条、字段少 |
| 扫描/拍照识别 | 对象浏览器 → **扫描录入** | 票据、单据、纸质表单 |
| 手机拍照 | 扫描录入 → **手机扫码拍** | 用手机拍，电脑端接收 |
| 批量文件 | 扫描录入 → **文件识别（批量）** | 一次导入多张图片/PDF/Word |
| 表格导入 | 数据层 → 导入 | 已有 Excel/CSV 数据 |

**扫描录入要点**
- 先选「录入到」的对象类型（如「支出」）
- 多商品小票选「支出」，识别后可逐条修改**商品明细**（名称/数量/单价/小计），每条独立入库，便于按商品统计
- 识别有误的字段可直接点击修改后再确认入库
- 手机端可独立完成「拍照 → 核对 → 确认入库」，无需回电脑操作

### 查找与修改

- **搜索**：对象浏览器顶部搜索框，匹配属性值
- **筛选**：按类型切换；数据视图可保存常用筛选
- **修改**：点开对象 → 编辑 → 保存（有权限限制，见「权限」）
- **删除**：对象详情右上角垃圾桶 → 二次确认。删除「支出」会**连带删除其商品明细**，系统会提示影响范围

### 分析与报表

- **仪表盘**：左侧导航 → 概览，看核心指标与趋势
- **数据血缘**：查看数据从来源到应用的流转关系
- **探索**：数据层 → 探索，按维度组合分析

### 知识与 AI

- **知识库**：上传文档 → 系统解析分块 → 可在智能助手中被引用作答
- **智能助手**：右下角或左侧导航进入，用自然语言提问；回答会标注引用来源
- **AI 工作流**：应用构建 → 工作流编排，可视化搭流程（识别/分类/通知/审批）

### 协作与治理

- **审批**：需审批的动作会在「审批中心」等待处理，可同意/驳回并留言
- **审计**：所有关键操作（登录、增删改、审批、配置变更）都有记录，管理员可查
- **通知**：审批、任务、系统消息在右上角铃铛

## 三、空间与权限

- **组织空间**：企业业务数据（设备/工单/客户等），按角色授权
- **个人空间**：个人数据（消费、笔记、计划），仅自己可见
- 页面顶部可切换空间；看不到某类数据时，先确认**当前所在空间**是否正确

权限级别（由管理员分配）：
- **只读**：可查看，不能改
- **可编辑**：可新建/修改
- **完全**：可编辑 + 删除

## 四、手机扫描录入

1. 电脑端：对象浏览器 → 扫描录入 → 选类型 → **生成二维码**
2. 手机（与电脑同一 WiFi）：扫码打开拍照页
3. 拍照 → 上传并识别 → 核对修改 → **确认入库**
4. 一张录完点「继续拍下一张」，同一二维码可连续拍多张
5. 会话 10 分钟内有效，过期后回电脑重新生成

> 手机打不开二维码？确认手机连的是同一网络，且链接里是电脑的**局域网 IP**（不是 localhost）。

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 录入后对象浏览器找不到 | 检查右上角**空间**是否切到了录入时所在的空间；检查**对象类型**筛选是否匹配 |
| 扫描只识别出总金额、没有明细 | 确认「录入到」选的是**主类型**（如支出）而非明细类型；票面有逐条商品时会自动拆行，无明细可手动「添加一行」 |
| 手机拍照报格式错误 | iPhone 在「设置 → 相机 → 格式」选「兼容性最佳」；或改用「选择图片」从相册上传 |
| 识别结果不准 | 换更清晰、光线充足、票面平整的照片；或在「补充要求」里写清规则（如「金额取合计」） |
| 某功能按钮点不动 | 多为权限不足（只读），请联系管理员授权 |
| 看不到别人的数据 | 行级隔离生效：跨部门数据需管理员授权对应空间权限 |
| 忘记密码 | 联系管理员重置，或使用邀请链接重新激活 |

## 六、数据安全须知

- 不要在个人空间存放需要团队共享的业务数据
- 上传的票据图片会发送到配置的 AI 视觉服务做识别（可能是外部服务），涉密票据请先与管理员确认是否已配置私有化模型
- 删除操作不可恢复（有审计记录但不保留内容），重要数据删除前建议先导出
- 定期修改密码，不要与他人共享账号
