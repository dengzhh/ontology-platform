## 三、审计中发现的遗漏任务（本轮已修复）

| 发现 | 处理 |
|---|---|

| `load.mjs` 2 处恒真断言（四卡配置、扫描素材复制） | 改为**回读校验**（settings key 数量 + JSON 可解析；目标文件存在且非空） |

| 42 页全标 `live` 但个别页有禁用入口 → 口径一致性 | 决策：**保留 live（主链路真实）**，收紧定义并在本报告 §四如实列出禁用入口；文档明确「live ≠ 无边界」 |
| 文档数字/状态大面积过时（21/22 工具、23/28 路由组、25/29 截图、40/2 演示态、89/187 冒烟、41/118 装载、旧英文页名） | 全量统一：README / CONVENTIONS / TECHNICAL-GUIDE / FEATURE-MATRIX / api-contract（补 5 组端点）/ checklist / e2e / tests/README |

## 四、仍待完成 / 明确边界（按优先级）

### P0 — 发布前必做（外发动作，需用户确认）

1. **推送 GitHub**：当前 15 次提交全在本地、无 remote；`v1.0.0` tag 指向旧提交。建议新建远程仓库后 `git remote add origin … && git push -u origin master --tags`，并把版本推进为 **v1.1.0**（或把 v1.0.0 tag 移到当前 HEAD）。README 的 `git clone <repo-url>` 占位符需替换。
2. **补 LICENSE 说明**：MIT 已入库，README 可加一行"开源协议：MIT"。

### P1 — 口径/状态一致性（可选）

3. **禁用入口**：岗位工作区「编辑布局/新建工作区」、地理空间「新建分析视图」、安全与标记「新建标记」、应用市场用户产品「一键安装」为永久禁用。它们都带醒目标注，属诚实边界；若要消灭禁用入口需补后端接口（工作区布局元数据、地图分析视图、Markings 管理、用户产品安装映射）。
4. **本地引擎覆盖**：`compare_objects` 在 LLM 未配置时不猜集合，改为引导用户在对象浏览器保存两个对象集——属可接受降级，若要完全对等需本地根据问法解析已保存探索 id。

### P2 — 外部系统级能力（企业化升级，非本地基线必需）

5. **安全治理**：查询管道实时掩码、生命周期到期自动归档调度器。
6. **数据连接**：PG/MySQL/Kafka/SAP 驱动与凭据代理（当前仅登记参数）。
7. **代码资产**：Git PR / CI / 分支合并集成。
8. **调度 / 部署**：COPT/OR-Tools 精确求解器、真实 K8s/CI-CD 执行。
9. **基础设施**：PostgreSQL/pgvector、OIDC/SSO、JWT 吊销、多实例/PM2/Docker、SLA 监控、服务端 token 计量。
10. **分析深度**：多表 join 聚合、流式时序、Fusion 多类型工作表与公式求值、地图 GIS 地理编码。

> 上述 P2 项在 `status.ts` note、各页横幅、`TECHNICAL-GUIDE §5` 与本地 `docs/local-benchmark.md`（gitignore）中均已如实标注，**不存在虚标**。
