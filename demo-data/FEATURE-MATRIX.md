## 一、快速开始（3 步）

```bash
# 1. 启动平台
npm run dev

# 2. 生成外部数据源（独立 SQLite 库，4 表 120 行）
python demo-data/build_external_db.py

# 3. 一键装载全功能验证数据（幂等，可重复运行）
node demo-data/load.mjs
#    期望输出：通过 118/118
```

- 默认账号：`chen.xingye / ontos@2026`
- 浏览器打开 `http://localhost:5174`，按下方矩阵逐项体验
- ⚠️ **空间提示（重要）**：平台是多空间隔离的。`load.mjs` 把**绝大多数验证数据装在组织空间「星辰智造集团」**（`sp-org-default`），只有 6 条消费数据 + 扫描明细装在**个人空间「陈星野的个人空间」**。顶栏可切换空间；若某页列表为空，先确认当前空间是否正确（尤其从个人空间切回来后）。
- **清理**：`node demo-data/load.mjs --clean`（按装载清单精确删除本脚本数据，不动种子数据）

## 六、注意事项（诚实边界）

- **调度优化 / 部署发布**：均为本地真实引擎（启发式求解 / 编排状态机），如实标注非 COPT/OR-Tools、非真实 K8s/CI-CD 执行。
- **时序曲线**：模拟与真实采集并列（页面标注）；本批已装载 3 指标多时刻真实序列（health_daily / downtime_hours_daily / hydraulic_temp_hourly 八小时越阈曲线）。
- **管道拓扑**：已是真实节点编辑器（3 条典型管道 / 8 类节点 / 拖拽·连线·撤销·保存布局持久化）；但「运行」仍是统计扫描，不执行真实 ETL 节点。
- **数据血缘**：默认只画每层前 8 个代表性节点，其余聚合为「+N」节点可展开；完整视图每层上限 40，全量数据保留在右侧列表检索，避免节点过多拖慢页面。
- **AI 识别**：视觉/文本模型依赖外部网关；网关不可用时 `/scan/recognize-text` 有平台 AI 网关兜底，`/knowledge/docs` 分块有本地哈希向量降级（`mode=local`），不会伪造成功。
- **数据连接非 SQLite 类型**：仅登记参数，不发起真实连接（诚实标注）。
- `load.mjs` 通过 `settings.load_manifest` 装载清单 + 静态名称清单精确清理本脚本数据（118 项断言幂等），`--clean` 不会动种子数据；外部库 `external/enterprise.db` 是独立文件，删除它即可完全移除外部数据源。
