# 关键业务闭环 · 端到端测试剧本

> 用于人工回归 / 交付验收。每条剧本都是「真实读写闭环」，不做静态演示。
> 自动化 API 层断言见 `tests/smoke.mjs`；页面逐页勾选见 `tests/checklist.md`。
> 前置：`npm run dev`，用 `chen.xingye / ontos@2026` 登录，默认空间「星辰智造集团」。

---

## 剧本 1：对象 CRUD → 审计留痕（P3 / P4 基础）

1. 进入「对象浏览器」`/ontology/explorer`，选「生产设备」，新建一条对象（各字段按类型填写）。
2. 在列表中找到它，编辑一个属性并保存。
3. 打开「审计日志」`/gov/audit`，按操作人/动作过滤，应能看到「新建对象」「更新对象」两条。
4. 回到对象浏览器删除该对象（确认弹层有取消），刷新确认消失。
5. **预期**：全程数据落 `objects` 表，审计可查；enum 字段填非法值应被 400 拦截。

## 剧本 2：需审批动作 → 通过写回 → 审计（P4）

1. 「审批中心」`/gov/approvals` 记录当前待审批数。
2. 通过一个对象动作发起需审批变更（动作类型中 `needsApproval=true` 的那些）。
3. 审批中心出现新单；点「通过」→ 目标对象数据被写回；点「驳回」→ 单据关闭且数据不变。
4. **预期**：通过即执行、驳回不写回，两种路径都留审计。

## 剧本 3：知识入库 → 检索 → 抽取落地（P5）

1. 「知识库」`/knowledge/library` 上传一篇 ≥10 字的文档，等待分块/向量化完成。
2. 「知识检索」`/knowledge/search` 搜文档里的关键词，命中片段可溯源。
3. 「知识抽取」`/knowledge/extract` 选该文档运行 LLM 抽取 → 得到候选 → 点「落地为本体类型」。
4. 到「本体管理器」确认新类型出现；再次点落地应提示「此前已落地，未重复创建」（幂等）。
5. **预期**：候选状态变「已落地」，新 objectType/linkType 真实入库，审计留痕。

## 剧本 4：扫描识别 → 写回本体（P6）

1. 「识别模板」`/admin/scan-templates` 新建一个自定义模板，填字段映射（如 `价税合计 → amount`），保存后**重新编辑确认映射未被清空**。
2. 「对象浏览器」用扫描录入（拍照/上传图片或文件）识别一张票据，选该模板。
3. 确认识别结果 → 提交 → 新建对象。
4. **预期**：字段映射真实生效，对象按映射后的属性落库；审计可查。

## 剧本 5：Fusion 双向写回（P10）

1. 「智能表格」`/analytics/fusion` 显示 5 个真实 Factory 对象。
2. 双击某个单元格（如「备注」）改值并回车。
3. 提示「已写回本体」，刷新页面值仍在；到「对象浏览器」查该 Factory 对象属性值一致；审计有「Fusion 单元格写回」。
4. **预期**：单元格编辑真实 PATCH 对象，非前端假改。

## 剧本 6：管道运行闭环（P10）

1. 「管道构建」`/data/pipelines` 新建管道（默认含 source + output 两节点）。
2. 选中 → 「校验管道」应通过；「发布」版本变 v2；「运行」提示处理行数 = 当前空间对象数。
3. 运行历史出现新记录（状态/时长/明细真实），统计卡「运行记录 / 累计行数」同步。
4. 删除该管道（连带运行记录清理）。
5. **预期**：`pipelines` / `pipeline_runs` 真实落库，不用审计伪造指标。

## 剧本 7：报告草稿 → 发布 → 回填（P10）

1. 「智能报告」`/analytics/notepad` 编辑标题与正文 → 「保存草稿」→ 报告列表出现。
2. 点「发布月报」→ 状态变已发布。
3. 点列表里的报告 → 标题/正文/AIP 结果回填；用「AI 润色」产生结果后再次保存，刷新可回显。
4. 删除报告（确认+取消）。
5. **预期**：`reports` 表真实 CRUD，审计留痕，AIP 结果随报告持久化。

## 剧本 8：接口契约符合性（P2）

1. 「本体管理器」→ 接口 Tab → 新建接口，契约属性填 `code`（生产设备确实有此属性），实现类型选「生产设备」。
2. 点「校验符合性」→ 显示「✓ 生产设备 满足契约」。
3. 编辑该接口，把契约属性改成 `warranty`（生产设备没有）→ 再校验 → 显示「✗ 生产设备 缺少：warranty」。
4. 删除接口。
5. **预期**：校验有真实判别力，`interface_types` CRUD 落库。

## 剧本 9：API 密钥安全性（P10）

1. 「开发者工具」→ API 密钥 Tab → 新建密钥，弹层显示明文 key 并提示「仅显示一次，请立即复制」。
2. 关闭弹层后刷新列表：只有前缀，无明文、无哈希。
3. 删除密钥（确认）。
4. **预期**：库里只存 SHA-256 哈希；明文永不二次回显。

## 剧本 10：自动化规则条件生效（P7）

1. 「自动化引擎」新建规则，条件表达式填 `健康度 < 60`，动作选通知。
2. 编辑规则修改条件 → PATCH 保存。
3. 触发一次对象变更，观察 `hitCount` 与通知是否按条件命中。
4. **预期**：condition 提交、落库、引擎解析三处一致（非「字段存在但不用」）。

---

## 回归顺序建议

```
剧本 1（对象基础）→ 2（审批）→ 3（知识）→ 5（Fusion 写回）
→ 6（管道）→ 7（报告）→ 8（接口）→ 9（密钥）→ 10（规则）→ 4（扫描，需图片素材）
```

每个剧本结束后在「审计日志」确认至少一条对应留痕，是判断「真闭环」的最快方法。

## 清理提醒

- 人工测试产生的数据建议命名带 `E2E_` / `TEST_` 前缀，便于识别与删除。
- `tests/smoke.mjs` 会自动清理 `SMOKE_` 前缀数据，人工测试数据需自行删除。
- 如需完全重置到种子态：`npm run seed`（**会清空用户新增的所有对象/文档/配置，谨慎**）。
